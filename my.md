# SEFW Brand Palette

The Sexual Empowerment For Women palette. Use only these colours (and Marcellus
headings + Lora body) for all decks and branded assets.

| Swatch | Hex | Name | Use |
|---|---|---|---|
| ⬛ | `#1d283c` | Navy | Primary dark background, text on light |
| 🟣 | `#74234f` | Plum | Dark accent background, accents on light |
| 🌸 | `#e4bbc2` | Blush | Soft light background |
| 🩷 | `#fce8ea` | Pale pink | Lightest background, light text on dark |
| 🩵 | `#7ca1a5` | Sage | Mid background / accent |
| 🟦 | `#224652` | Deep teal | Dark background |
| 🟡 | `#c9a86d` | Gold | Accent, eyebrows, dividers, text on dark |

**Fonts (locked):** Marcellus (headings), Lora (body).

**Deck usage:**
- Dark backgrounds (Navy, Deep teal, Plum): light text (Pale pink), Gold accents.
- Light backgrounds (Pale pink, Blush): Navy text, Plum accents.
- Mid (Sage, Gold): Navy text, Plum accents.
- No rust, no copper, no cream, no black outside these hexes.
