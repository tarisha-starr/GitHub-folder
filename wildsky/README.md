## The short version

The site does the emotional half beautifully — the voice, the founders, the
photography, the Brew Table paragraph. It does almost none of the deciding half:
no weight comparison, no dimensions, no reviews, no shipping promise where she's
choosing, free NZ shipping buried in a policy page, and a homepage title tag that
just says "Wild Sky Coffee".

Four questions every visitor is holding, none of which the site answers:

1. Which one do I buy?
2. Will it fit / nest / go on my stove?
3. Can I trust you with $59?
4. What does delivery cost and when does it arrive?

Fix those four and you don't need a redesign.

## Things to verify before publishing

These are flagged throughout, collected here so they don't get lost:

- **Alpine Pot: 1000ml at 79g.** Extraordinarily light for a one-litre titanium
  pot. Weigh it. If it's right, it's the headline of that page.
- **Wild Coffee Scooper weight** — the description says 25g, the spec table says
  26g.
- **Dimensions for all ten products.** Only the Brew Table has any.
- **What nests inside the Alpine Pot.** Measure it before claiming it.
- **Whether the double-wall Kea Cup can go over a flame.** Confirm with your
  supplier, then say it plainly on the page. It's both a safety line and a
  buying-decision line.
- **Whether GA4 and the Meta pixel are actually firing.** Neither appears in the
  page source; they may be installed as Shopify web pixels. Check Settings →
  Customer events.
- **"Designed in New Zealand" vs "made in New Zealand."** Keep saying designed
  unless the gear is manufactured here.
